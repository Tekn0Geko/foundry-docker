# Run Foundry VTT in a Docker Container

This project is just a couple of folks simply sharing how they setup Foundry VTT to run in a local Docker
Container. The need for such a setup came about when version 14 dropped support for macOS Monetery
but buying a new Mac seemed like an uneeded expense. This was bound to happen at some point so this
was viewed as a positive forcing function. Getting this to work via a container means there will be
a less fragile option available that can be used across platforms in the future. 

There is no warranty with this solution and no guarantee it will work for you. However, feel free to
submit an issue if you come across a bug or an optimization. This is a for-fun project mainly. Also
keep in mind this approach is one of many. See the resources list below for links to other Foundry
VTT solutions, like just running locally via Node.
